# my-first-ai-app

A small project for learning how to code with Cursor and GitHub.

## What this is

This repo is a sandbox — a safe place to try things out, make changes, and see how version control works without worrying about breaking anything important.

## Getting started

1. Open this folder in Cursor.
2. Edit files (like this README).
3. Save your changes.
4. Ask Cursor to commit and open a pull request when you're ready.

## Useful terms

| Term | What it means |
|------|----------------|
| **Repository (repo)** | A project folder tracked by Git |
| **Commit** | A saved snapshot of your changes |
| **Branch** | A separate line of work (like a draft copy) |
| **Pull request (PR)** | A request to merge your changes into the main project |
