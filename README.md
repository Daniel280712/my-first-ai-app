# my-first-ai-app

Personal projects lab on **Raspberry Pi 3**.

## Active project: GNSS / LTE Lab

Learn GPS + LTE on the Pi. **Track live on your phone** (browser / home-screen app).

**Start here:** [pi-gnss-lte/README.md](pi-gnss-lte/README.md)

```bash
cd pi-gnss-lte
sudo ./scripts/install.sh
# Phone: http://<pi-ip>:8090 → Add to Home screen
```

- Pi 3 + **USB GPS dongle** (~£15)
